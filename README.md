# TP1 – Pipeline ETL Météo & Irrigation

## Objectif du projet

Ce projet implémente un pipeline ETL complet pour le traitement de données météorologiques provenant de stations de mesure. Il couvre l'ensemble du processus: extraction, nettoyage, transformation, génération de rapports qualité, enrichissement par feature engineering et export.

## Technologies utilisées

- **Python 3.10+** : Langage principal
- **Pandas** : Manipulation et analyse des données
- **NumPy** : Calculs numériques
- **Logging** : Traçabilité des opérations
